# IPTools

IPTools is a Minecraft server plugin that helps staff identify players by checking their IP addresses and finding alternate accounts (SECs).

Commands

/playerip <player> — View a player's IP address.
/secs <player> — View a player's alternate accounts (SECs).

LuckPerms Permissions

To allow a player to view IP addresses: /lp user [nick] permission set iptools.playerip true

To allow a player to view SECs: /lp user [nick] permission set iptools.secs true

Replace [nick] with the player's Minecraft username.

Perfect for server moderation and investigating possible alternate accounts.
